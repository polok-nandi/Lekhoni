# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Lekhoni and our users' document privacy seriously.
If you discover a security vulnerability or sensitive information exposure:

1. **Do not disclose publicly.**
2. Email the author directly: **Polok Nandi** at `nandipolok@gmail.com`.
3. Provide detailed steps to reproduce the issue.
4. We will acknowledge receipt within 48 hours and work on a fix promptly.

### Privacy Guarantees
- Lekhoni saves documents strictly locally on-device via Room SQLite.
- AI requests to Google Gemini are only executed on explicit user action and are never sent automatically.
- No telemetry or document tracking is embedded.
