# Contributing to Lekhoni (লেখনী)

Thank you for your interest in contributing to Lekhoni! Lekhoni is an open-source project dedicated to empowering Bengali speakers and multilingual writers worldwide with a world-class, accessible document editor.

## Getting Started

1. **Fork the Repository**: Fork on GitHub and clone to your local machine.
2. **Set up Environment**: Open the project in Android Studio. Ensure JDK 17+ and Android SDK 36 are installed.
3. **Branching Model**: Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Code Standards**:
   - Write clean, modern Kotlin with Jetpack Compose.
   - Follow Material Design 3 guidelines.
   - Respect Bengali typography rules (Unicode normalization, conjunct positioning).
   - Never commit API keys or private secrets.
5. **Run Tests**:
   ```bash
   gradle :app:testDebugUnitTest
   ```
6. **Submit a Pull Request**: Provide a clear summary of your changes and any relevant screenshots.
